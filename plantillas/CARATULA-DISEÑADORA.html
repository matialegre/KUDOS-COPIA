Cómo revisar

  1. Hacé clic en "ABRIR PREVIEW" de cada template para verlo en el navegador.
  2. Cada preview muestra la maqueta de referencia arriba y la implementación real abajo.
  3. Usá los botones de estado para indicar si el template está aprobado, requiere revisión o está rechazado.
  4. Dejá tus comentarios en el campo de notas de cada card.
  5. Al terminar, podés imprimir esta página con Ctrl + P para archivarla.
